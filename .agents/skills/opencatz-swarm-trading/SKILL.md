### Layer 3: Security & Runner Token Audit Checklist

2. 👨‍💻 **Dev Holding %:** MUST be <= 10% (allows marketing/airdrop reserve).

6. 🎣 **Phishing Risk %:** MUST be <= 3%.

8. 🚫 **NoMint:** Mint Authority MUST be disabled.
